پروژه اندروید Simple AI — v.0.0.1
=====================================

این پروژه یک پوسته اندرویدی برای رابط چت Simple AI دارد.
ویژگی‌ها: تم سبز و مشکی، نسخه v.0.0.1، چت متنی؛ بدون ویس و ساخت عکس.

مهم: این ZIP خودش APK نیست. فایل APK باید با Android SDK ساخته شود.

ساخت APK به‌صورت خودکار:
1. پس از بارگذاری تمام فایل‌های پروژه، به زبانه Actions بروید.
2. گردش کار Build Simple AI APK را اجرا کنید یا منتظر اجرای خودکار پس از push بمانید.
3. پس از موفقیت، از قسمت Artifacts فایل Simple-AI-v0.0.1-debug-apk را دانلود کنید و app-debug.apk را از ZIP بیرون بیاورید.

چت این نسخه فعلاً پاسخ‌های نمایشی دارد و به مدل آنلاین متصل نیست. برای اتصال واقعی، API و سرور واسط امن لازم است. کلید API را در فایل HTML یا APK قرار ندهید.
